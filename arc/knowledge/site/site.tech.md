# How this site is built

This is Mehul's portfolio site, built with **Next.js 16, React 19, TypeScript and Tailwind CSS**. Animations use **Motion** and **GSAP** (ScrollTrigger, SplitText), smooth scrolling uses **Lenis**, and the diffusion hero, RoadGuard simulation and LiDAR point cloud are hand-written **Canvas 2D**. It's hosted on Vercel.
