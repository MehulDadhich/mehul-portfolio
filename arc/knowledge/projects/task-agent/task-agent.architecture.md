# AI Task Manager: architecture

**AI Task Manager** works as a pipeline: **Instruction** → **LangGraph** → **Gemini** → **Firestore** → **Alarms**. Instruction: The user writes a task in natural language. LangGraph: An agentic workflow coordinates interpretation, state management and tool execution across steps. Gemini: Classifies priority and category, extracts natural-language dates and schedules the task. Falls back to keyword rules if the AI service is unavailable. Firestore: Protected Express REST endpoints with Firebase Authentication; tasks persist in Firestore. Alarms: Socket.IO pushes real-time alarm notifications for tasks that are coming due.
