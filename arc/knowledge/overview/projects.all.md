# All projects

Mehul has 7 separate main systems:
- **RoadGuard** (Two-tier accident detection with a VLM): A two-tier pipeline that runs fully offline. Tier 1 runs on every frame: detection, tracking and a kinematic rules engine raise an immediate alert. Tier 2 sends uncertain events to a local vision-language model, which confirms or rejects them with a yes or no.
- **Warehouse Monitoring System** (Warehouse intelligence platform): A full-stack platform that runs YOLO11 on RTSP cameras, reads licence plates at the gate, streams events to live dashboards and gives each role the controls it needs. Its code is public on GitHub.
- **AI Task Manager** (LLM agent for task planning): An agentic workflow that turns a plain-language instruction into a structured task with priority, category and due date, and sends real-time alarms before it is due. Its code is public on GitHub.
- **ASTRA** (Industry · Infrax.ai · AI operations agent): An AI assistant built into Cygnus. Operators ask in plain language, and an agent answers from live data through tools that run with the operator's own permissions and site scope, explains features from the product docs, and proposes changes behind a confirmation card. It runs on a self-hosted Qwen3-4B on CPU.
- **Arc** (RAG assistant on this site, with a QLoRA fine-tune): A retrieval-augmented generation (RAG) assistant on a self-hosted open-weight model. It answers only from facts retrieved from this site, remembers each visitor's conversation and acts on the page after asking. Its earlier model was fine-tuned with QLoRA and evaluated against the base model on held-out questions.
- **Rehearse** (AI mock interviewer with voice and a scored debrief): A voice-first mock interviewer. It speaks each question, listens to the spoken answer, probes vague answers with follow-ups like a real first round, and ends with a written debrief scored against a rubric, with a stronger version of every answer. Its code is public on GitHub.
- **Traffic Management & Control System** (Industry · Infrax.ai): The computer-vision module of an Advanced Traffic Management System: continuous RTSP ingestion, YOLO detection, and incident events delivered to operators through APIs, dashboards and alerts.
RoadGuard is the featured one, with a full scroll-through of its pipeline.
