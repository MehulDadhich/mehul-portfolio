# LLM and agent work

On the LLM side, Mehul built the **AI Task Manager**, a LangGraph agent that turns plain-language instructions into structured tasks using Gemini, with a keyword fallback when the model is down; at Infrax.ai he built **ASTRA**, a tool-calling operations agent on a self-hosted Qwen3-4B that answers from live data within each operator's permissions; and **Arc**, a RAG assistant with hybrid search on a self-hosted Llama 3.2 3B that acts on the page only after the visitor agrees. He fine-tuned Arc's earlier model with **QLoRA** and evaluated it on held-out questions. In RoadGuard he uses a **vision-language model (Qwen3-VL)** to verify accidents. He also lists multi-agent systems, MCP, re-ranking and vector databases among his skills, though no project on this site uses them yet.
